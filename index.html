개인정보 처리방침

오늘의헬스 · 시행일 2026년 10월 11일

1. 수집하는 정보

오늘의헬스는 개인정보를 수집하지 않습니다. 사용자가 앱에 입력하는 운동 기록, 루틴, 체중, 이름은 모두 사용자의 기기 안에만 저장됩니다.

2. 서버 전송 여부

이 앱은 서버가 없습니다. 어떤 데이터도 외부로 전송되지 않으며, 회원 가입이나 로그인을 요구하지 않습니다. 광고나 분석 도구도 포함되어 있지 않습니다.

3. 데이터 삭제

앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다. 앱 안의 기록은 사용자가 직접 지울 수 있습니다.

4. 권한

앱은 진동(세트 완료 알림) 외에 별도의 기기 권한을 요구하지 않습니다.
